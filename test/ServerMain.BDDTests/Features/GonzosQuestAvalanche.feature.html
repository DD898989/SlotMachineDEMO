💡 Gonzo's Quest Avalanche 連鎖掉落物理機制解析
  • 重力連鎖消去 (Gravity Fall)：每一輪中獎連線的符號將產生碎石粉碎特效消散，上方現存方塊在重力加速度下垂直掉落填補，頂部由滾輪新方塊自天而降補齊。
  • 免扣下注成本機制：連鎖掉落旋轉或 Free Fall 免費旋轉時，後端 game.FreeMode() == true，玩家點數錢包扣款為 0 點。
  • 滿貫階梯乘倍機制： 常規模式依序躍升 1x ➔ 2x ➔ 3x ➔ 5x (滿貫封頂)； Free Fall 模式依序躍升 3x ➔ 6x ➔ 9x ➔ 12x ➔ 15x (終極滿貫封頂)。

func (s *Cascade5x3) PushFall(reels Reelx) {
  for x, hr := range s.Hits {
    var sr = &s.Grid[x]
    var n = 0
    for y, h := range hr {
      if h > 0 { // 此格中獎被消除
        for i := range y {
          sr[y-i] = sr[y-i-1] // 上方方塊重力下墜
        }
        n++ // 該軸消除計數 +1
      }
    }
    s.Seed[x] -= n // 滾輪指標往上方回退 n 格
    for y := range n {
      sr[y] = ReelAt(reels[x], s.Seed[x]+y) // 上方滾輪注入
    }
  }
}
